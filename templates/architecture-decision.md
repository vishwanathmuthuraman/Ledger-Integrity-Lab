# Architecture decision template

Status: proposed.

## Problem and measured constraint

State the actual bottleneck, baseline profile, dataset size and reproduction commands.

## Options

Compare existing Python/SQL path with a bounded alternative. Include implementation cost, skills, observability, data movement and maintenance.

## Decision and contract preservation

Record the chosen option, evidence, interface boundaries, parity checks and rollback path. Language choice does not prevent public copying.

## Revisit condition

Name the measurable change that would justify reconsideration.
